CLAUDE DESKTOP - OFFLINE CODE SESSION SYNC (Mac / Windows / Linux)

IMPORTANT: REPLACES THE OLD FOLDER-LINKING VERSION
Old linked account folders could let history open while preventing Claude from
saving recent sidebar entries. Download this version and run Sync/repair with
Claude closed. It replaces recognized links with NORMAL folders and saves
backups. Missing sidebar entries may need recovery from existing transcripts;
ask the maintainer and see README.md. Do not delete transcript files.

QUICK STEPS
1. Extract the whole ZIP and replace old downloaded copies.
2. In Desktop, sign into each intended account/organization and open Code once.
3. Finish your work and QUIT CLAUDE COMPLETELY (Cmd+Q on Mac; also quit the
   system-tray icon on Windows if it remains running).
4. Open the matching launcher:
   Mac: double-click Claude Session Sharing.command
   Windows: double-click Claude Session Sharing.cmd
   Linux: open a terminal in this folder and run:
     bash "./Claude Session Sharing.sh"
5. Press Enter for Sync / repair old setup. Read the preview, type SYNC,
   and press Enter. Keep Claude closed until success.
6. Reopen Claude > Code and open a familiar conversation to check its history.
7. To show folders: Group and sort > Group by > Folder (once per organization).

BEFORE EVERY ACCOUNT SWITCH
Finish work > quit Claude > run Sync > reopen Claude > switch accounts.
New conversations are NOT copied while the app is running.

OPTIONAL: AUTOMATIC SYNC ON MAC
Choose option 5 once to enable sync after fully quitting Claude.
Then: finish work > quit Claude > leave it closed about 5-10 seconds > reopen
and switch accounts. You do not need to run Sync manually after a successful
automatic run. If you reopen before five seconds pass, copying is deferred
until a later full quit. Switching accounts inside an open app does not sync.
Option 6 shows status/errors. Option 7 disables the watcher.
It starts at future Mac logins, skips unchanged records, and uses the same
backups and normal folders. Re-run option 5 after updating the helper.
Disable it before Undo if you want future quits to stop copying.
Windows and Linux remain manual.
This is local copying between your OWN accounts on one computer, not sync
between teammates, computers, or Claude cloud accounts.

REQUIREMENTS
Python 3.9+. The launcher checks for Python; install from python.org or ask IT
if missing. Keep the helper and launchers together. No extra Python packages. The optional Mac watcher installs a user-level
LaunchAgent and stable helper copy; it does not download code.
Use your normal user account; do not run as administrator or with sudo.
If scripts are blocked by your company, ask IT. Do not disable protections.

STATUS / UNDO
Option 2 reports normal folders, legacy links, and the last sync status.
Option 3 restores the last pre-sync account snapshots. Type UNDO to confirm.
Current files are backed up again before restoring, so later records remain
preserved there. Undo never restores account-folder links. Original transcript
contents are not changed. If interrupted, keep Claude closed and run Undo. Disable auto sync first
if you want subsequent quits to stop copying.

LIMITS
All detected account folders in the selected native Desktop store are included.
Logins, cloud chats, Cowork, saved environments, sidebar layout, subscriptions,
organization restrictions, and connector authentication remain separate.
Imported records discard account-bound Remote Control/connector references;
reconnect those services under the intended account. Existing missing
transcripts cannot be reconstructed. Newest file modification time wins when
records conflict; pre-sync variants are retained in each run's backup.
Deletions are not propagated and may be copied back; archive sessions instead.
Use one active Desktop login and run one sync operation at a time.

BACKUPS AND PRIVATE DATA
The printed backup path is under the native Claude data directory:
  codex-session-sharing-backups/offline-<timestamp>/
Account folders remain under claude-code-sessions; shared-code-sessions is
only an archive from the last sync. Keep backups and transcript files private.
Do not distribute them with this package. No credentials are included here.

For detailed steps, custom data directories, recovery commands, troubleshooting,
and compatibility limits, read README.md.

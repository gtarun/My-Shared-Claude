Each account keeps its own login, billing and connectors. Only the local Code session list is shared.

Setup in about two minutes

No Git, no packages, no admin rights.

1

Open Code once per account

Sign in to each account in Claude Desktop and open the Code tab.

2

Quit Claude

Finish your tasks, then ⌘ Q on Mac or Exit on Windows.

3

Double-click the launcher

.command, .cmd or .sh, one for each OS.

4

Type SHARE

Check the preview, confirm, and reopen Claude. That's it.

Needs only Python 3.9+. To add a new account later, run it again.

Preview before anything changes

You see exactly what it will do.

The first pass changes nothing. It shows what it found and what stays separate. Nothing happens until you type SHARE.
